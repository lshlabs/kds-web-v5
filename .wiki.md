# Project Summary
KDS (Kitchen Display System) is an advanced dashboard solution aimed at optimizing kitchen operations through real-time analytics and performance insights. It empowers restaurant staff with critical data to enhance workflow, manage orders efficiently, and ultimately improve operational efficiency. By utilizing modern web technologies, KDS fosters seamless communication and data visualization, enabling kitchen teams to make informed decisions that drive business growth.

# Project Module Description
- **Dashboard**: Displays key performance indicators (KPIs) related to kitchen operations.
- **Order Flow Chart**: Visualizes the flow of orders throughout the day, helping to identify peak times.
- **Kitchen Status**: Provides real-time updates on the status of kitchen operations.
- **Menu Performance**: Analyzes the performance of menu items based on sales data.
- **Operation Insights**: Offers insights and alerts regarding kitchen efficiency and operations.
- **Platform Stats**: Displays detailed statistics and trends related to platform performance, including total orders and revenue.

# Technology Stack
- **React**: A JavaScript library for building user interfaces.
- **TypeScript**: A typed superset of JavaScript for better tooling and type safety.
- **Vite**: A fast build tool and development server.
- **Tailwind CSS**: A utility-first CSS framework for styling.
- **Recharts**: A charting library for building responsive charts.
- **Lucide React**: A collection of icons for React applications.

# Usage
1. Install dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```bash
   pnpm run build
   ```
3. Run the development server:
   ```bash
   pnpm run dev
   ```
